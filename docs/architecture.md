# Architecture

```
src/
  app/          bootstrap + overlay host loop
  core/         registry, wot_offsets, shared models, logger lib
  features/     one package per cheat module (aim, esp, paint, loader)
  infrastructure/
    wot_driver/ process attach + memory scanner
```

Each feature implements `FeatureModule`. The overlay host ticks every module
once per frame; modules rate-limit themselves via internal timers.

## Offsets
`src/core/wot_offsets.py` is regenerated by `scripts/dump_offsets.py`
after every WOT patch. Never hardcode offsets inside a feature.

## Driver
`wot_driver` wraps `ReadProcessMemory` / `WriteProcessMemory` via pywin32.
No kernel driver, no anti-cheat interaction.
